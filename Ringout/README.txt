RINGOUT

On a Mac with Python 3, unzip the folder and open Start.command.
The launcher opens a local browser tab. Keep its Terminal window open while
you play. Press Control-C in that window to stop the server.

Join with any button or stick movement on a browser-compatible controller,
W for WASD, or Up Arrow for the arrow-key layout. Ready up in customization,
choose a mode, then select Start match. Use the ? menu for controls.

The game runs offline once the local server is running. Character looks,
menu themes, and co-op records are saved in cookies in your browser.
Controller vibration depends on browser and controller support.

Rounds starts everyone cardless. Tap shove up close, hold and release for
a stronger shove, dash to reposition, and time a dodge to parry.
Upgrades change the shove itself or reward landing one.
After a decisive fight, the losing players draft simultaneously. The
lowest score gets an extra choice. First to five wins by default.
Trick Draft, Rounds Quick, and Classic Rounds offer the earlier rules.
Open the ? menu to check inputs and rebind Trick for those modes.

Optional regression checks (Node.js 18+): node tests/cards.test.js
